Project overview

Built for the showroom

Carspec Motorsport Configurator is a Salesforce Sales Cloud org designed around the full lifecycle of a high-end supercar retailer — from customer enquiry and bespoke vehicle configuration through to closed order and automated follow-up.

"Automotive retail at the premium end is relationship-driven. The CRM needed to reflect that — a guided configuration experience, not a generic sales pipeline. Every step mirrors how a real supercar dealer would qualify and close a client."

The build demonstrates screen flow design, custom object modelling, Sales Cloud pipeline management, validation rules, record-triggered automation, and executive dashboard creation.

Data model

Object architecture

Three core layers — the vehicle catalogue, the customer pipeline, and the supporting account and contact records — connected through standard and custom relationships to power the guided configurator experience.

Custom object

The vehicle catalogue. 50 records across the world's leading performance manufacturers — Ferrari, Lamborghini, Mercedes-AMG, Aston Martin, and more.

Flow design

Guided configuration

A Screen Flow walks the sales consultant and client through the full configuration journey — from contact capture to vehicle selection to order confirmation — in three structured screens.

A separate record-triggered Flow fires when an Opportunity reaches Closed Won, automatically creating a follow-up task to schedule the delivery call — no manual step required.

01
Carspec Motorsport Configurator
Screen Flow — launched from App Nav
Screen 1 — Customer Info: name, email, phone, and enquiry source captured with validation
Screen 2 — Vehicle Picker: live lookup from Supercars__c catalogue, filter by make
Screen 3 — Configuration Summary: display selected vehicle, confirm options, preview price
On submission: auto-creates Contact and Opportunity record at Enquiry stage
02
Closed Won — Delivery Follow-Up
Record-Triggered Flow — Opportunity Stage = Closed Won
Triggers when Opportunity Stage changes to Closed Won
Creates a follow-up Task: "Schedule delivery call" assigned to Opportunity Owner
Due date set to 3 business days from close — no manual action required

Build process

How it was built

Built in a Salesforce Developer Edition org as the first project in the Administrator portfolio — establishing the build patterns, naming conventions, and documentation standards used across all subsequent projects.

Phase 1
App and object setup
Created the Carspec Motorsport Lightning app. Built the Supercars__c custom object with all fields — make, model, year, base price, colour, engine specs. Configured custom tab and page layout.
Phase 2
Catalogue population
Created 23 manufacturer Account records — Ferrari, Lamborghini, Porsche, Mercedes-AMG, Aston Martin, and more. Manually entered 50 Supercar records linked to manufacturer accounts with accurate base pricing.
Phase 3
Screen flow build
Built the 3-screen configurator flow — customer info capture with required field validation, vehicle picker with live record lookup from Supercars__c, and confirmation summary. Auto-creates Contact and Opportunity on submit.
Phase 4
Pipeline and automation
Created 10 Opportunity records across all 4 pipeline stages. Built the record-triggered Flow for Closed Won → auto-create follow-up task. Added validation rules: phone or email required on contact info screen.
Phase 5
Dashboard
Three reports built — Pipeline by Stage, Total Opportunity Value, and Closed Won Revenue. Three-component dashboard surfacing pipeline health, revenue metrics, and top manufacturers by deal value.
Architectural decisions

Key design notes

Custom object over Product catalogue
Salesforce's standard Products and Price Books were considered for the vehicle catalogue. Rejected in favour of a custom Supercars__c object — cleaner for portfolio demonstration, more flexible field design, and avoids the complexity of Pricebook management for a single-currency showroom.
Screen Flow over manual entry
The configurator flow is the centrepiece of the project — it simulates how a real showroom tool would guide a consultant through a client engagement, rather than having reps enter data directly into records. The flow enforces data quality and creates the correct object chain automatically.
Closed Won automation rationale
Post-sale follow-up is the highest-value touchpoint in premium automotive retail. The record-triggered flow ensures a delivery call task is always created without relying on consultant discipline — demonstrating how automation enforces process compliance at the critical moment.
